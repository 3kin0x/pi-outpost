# Scenario-to-test matrix

All delta scenarios and the applicable existing scenarios below are covered. Coverage was checked against the assertions in the named tests, not inferred from test names.

## Delta scenarios

| Capability | Scenario | Status | Test file and test name | Contract asserted |
|---|---|---|---|---|
| file | Rename a writable file | covered | `server/test/fileBrowser.test.ts` — `renames a writable regular file and preserves its content`; `server/test/file-lifecycle.test.mjs` — `renames a file and broadcasts both affected paths` | New path exists with original content, old path is absent, result identifies both paths, and both notifications are observed. |
| file | Refuse a rename that would overwrite | covered | `server/test/fileBrowser.test.ts` — `refuses a rename collision without changing either file`; `server/test/file-lifecycle.test.mjs` — `returns a correlated conflict without overwriting` | Conflict reason is returned and both source and destination contents remain unchanged. |
| file | Refuse a mutation outside the writable zone | covered | `server/test/fileBrowser.test.ts` — `refuses lifecycle mutations outside the writable zone`; `server/test/file-lifecycle.test.mjs` — `refuses a mutation outside the writable zone under the same request id` | Rename/delete/move are denied, read-only sandbox is denied, and source content remains. |
| file | Refuse an escaping mutation path | covered | `server/test/fileBrowser.test.ts` — `refuses escaping mutation paths`, `refuses lifecycle mutations through an intermediate symlink outside the root`; `server/test/file-lifecycle.test.mjs` — `refuses an escaping mutation under the same request id` | Traversal and intermediate-symlink escapes yield `outside-root`, no destination is created, and outside/source content remains. |
| file | Move a file into a folder | covered | `server/test/fileBrowser.test.ts` — `moves a file into a writable directory and refuses a collision`; `server/test/file-lifecycle.test.mjs` — `moves a file and broadcasts source and destination branches` | Destination contains the source content, source is absent, result is correlated, and both branches are notified. |
| file | Copy a read-only file into a writable folder | covered | `server/test/fileBrowser.test.ts` — `copies a read-only file into a writable directory without removing the source`; `server/test/file-lifecycle.test.mjs` — `copies a read-only file into a writable directory and keeps the source` | Source and destination both retain the content, collision is refused, result is correlated, and the destination branch is notified. |
| file | Open a Word document natively | covered | `server/test/fileBrowser.test.ts` — `launches a confined read-only file without a shell command` | The platform launcher receives the validated absolute file path as a separate argument without shell interpolation. |
| file | Refuse native opening outside the browser root | covered | `server/test/fileBrowser.test.ts` — `never invokes the launcher for an escaping path` | Traversal is refused as `outside-root` and the launcher spy remains untouched. |
| api | Correlated move result | covered | `server/test/file-lifecycle.test.mjs` — `moves a file and broadcasts source and destination branches` | The result carries the initiating request id, operation, previous path, and resulting path. |
| api | Correlated copy result | covered | `server/test/file-lifecycle.test.mjs` — `copies a read-only file into a writable directory and keeps the source` | The result carries the initiating request id, copy operation, and resulting destination path. |
| api | Correlated lifecycle error | covered | `server/test/file-lifecycle.test.mjs` — `returns a correlated conflict without overwriting`, `refuses a mutation outside the writable zone under the same request id`, `refuses an escaping mutation under the same request id` | Conflict, denied, and outside-root failures are returned under the initiating request id with machine-readable reasons. |
| components | Cancel a blank file rename | covered | `ui/src/components/FileTree.test.tsx` — `cancels a rename submitted with a blank name` | No rename callback fires, the input closes, the original row returns, and no validation error is rendered. |
| components | Confirm a file deletion | covered | `ui/src/components/FileTree.test.tsx` — `sends one delete request only after confirmation` | The confirmation names the file and exactly one callback fires after acceptance. |
| components | Cancel a file deletion | covered | `ui/src/components/FileTree.test.tsx` — `does not request deletion when confirmation is cancelled` | No callback fires and the file row stays rendered. |
| components | Drag a file onto a writable folder | covered | `ui/src/components/FileTree.test.tsx` — `moves a dragged file onto a writable directory` | Drag data carries the source and drop reports source plus destination directory. |
| components | Drag a read-only file onto a writable folder | covered | `ui/src/components/FileTree.test.tsx` — `copies a dragged read-only file onto a writable directory` | The drag indicates copy, the copy callback receives source and destination, and the move callback is not used. |
| components | Do not accept an invalid drop destination | covered | `ui/src/components/FileTree.test.tsx` — `does not accept a drop on a read-only directory` | Dropping on a read-only directory does not invoke the move callback. |
| components | Open a read-only file natively | covered | `ui/src/components/FileTree.test.tsx` — `opens a read-only file with its associated application` | Native-open remains available and reports the path while rename/delete controls are absent. |
| components | Reveal a truncated entry name | covered | `ui/src/components/FileTree.test.tsx` — `keeps the complete entry name available on hover when the row truncates it` | File and directory labels carry their complete entry name in the native tooltip attribute. |
| preview-file-attachments | Tool-readable binary selection becomes a path reference | covered | `ui/src/App.test.tsx` — `automatically references a tool-readable binary file: %s` | Both `.docx` and `.xlsx` binary-preview failures create removable path references and send `@path`, not bytes. |
| preview-file-attachments | Unsupported binary selection is not attached automatically | covered | `ui/src/App.test.tsx` — `does not attach an unsupported binary file` | A `.zip` binary-preview failure creates no automatic reference. |
